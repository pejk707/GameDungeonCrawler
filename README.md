# Последний фонарщик · The Last Lamplighter

> Спуститесь в недра горы с фонарём, в котором заканчивается масло, и разожгите погасшее Сердце Пламени, пока тьма не поглотила город — и вас.

Текстовая RPG в жанре dungeon crawler в духе **Zork**, написанная на **C++17**. Главный ресурс игры — масло в фонаре, и оно служит сразу трём целям:

- **время**: каждый шаг в темноте сжигает масло;
- **знание**: без света не видно ни предметов, ни выходов, остаются только звуки и запахи;
- **оружие**: вспышка обжигает существ тьмы.

Бои пошаговые, и враги заранее объявляют свои намерения. Мир состоит из 28 комнат в четырёх зонах, в нём 17 боёв (4 босса) и 9 загадок, а игру можно пройти примерно за час. Весь контент — комнаты, предметы, враги, тексты и ASCII-арт — хранится во внешних файлах.

## Сборка и запуск

**Windows** (основная платформа). Нужна Visual Studio 2022 с компонентом «Разработка классических приложений на C++» — в нём уже есть компилятор MSVC, CMake и Ninja.

```bat
build.bat          :: собрать игру в папку build\
play.bat           :: запустить (при первом запуске соберёт сам)
build.bat test     :: собрать и прогнать тесты
```

Лучше играть в **Windows Terminal** (в Windows 11 он стоит по умолчанию): окно пошире, шрифт Cascadia Mono или Consolas. Кириллица при вводе и выводе, цвета и рамки поддерживаются.

**Linux / macOS**:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
./build/lamplighter
```

Параметры командной строки:

| Параметр | Что делает |
|---|---|
| `--data DIR` | папка, в которой лежат `data/` и `art/` (по умолчанию ищется рядом с программой) |
| `--seed N` | фиксирует случайность: бои проходят одинаково |
| `--no-color` | без ANSI-цветов |
| `--width N` | ширина текста (по умолчанию 78) |
| `--script FILE` | выполнить команды из файла, затем продолжить вручную |
| `--demo FILE` | то же, но команды «печатаются» медленно — для записи видео |

## Как играть

Цель — добыть три Угля Сердца (в шахтах, в кузне и в склепе), открыть Печать Сердца в Зале Трёх Жил, победить Глотателя Света и `разжечь сердце`.

| Команда | Сокращение | Что делает |
|---|---|---|
| `идти север` | `с`, `ю`, `з`, `в`, `вв`, `вн` | перемещение |
| `осмотреться` · `осмотреть <что>` | `о` | описание комнаты или предмета |
| `взять <что>` · `взять всё` · `бросить <что>` | | предметы |
| `открыть <что>` · `читать <что>` | | контейнеры, записки, надписи |
| `использовать <что> [на <чём>]` · `надеть <что>` | | предметы, загадки, снаряжение |
| `фонарь` · `зажечь <что>` | | погасить/зажечь фонарь, жаровни, чаши |
| `атаковать <кого>` · `отдохнуть` | | бой, отдых и сохранение у жаровни |
| `инвентарь` · `статус` · `карта` · `журнал` | `и`, `ст`, `к` | информация |
| `сохранить` · `загрузить` · `помощь` · `выход` | `?` | служебные |

В бою: `атака` (`а`), `блок` (`б`), `вспышка` (`в`), `использовать <предмет>`, `бежать`, `осмотреть`.

Главное правило: **свет — это жизнь**. Каждая тёмная комната стоит 2 масла, без света тьма убивает за 4 хода, а зажжённая жаровня навсегда освещает комнату — у неё можно отдохнуть и сохраниться.

## Как записать видео с геймплеем

1. Соберите игру (`build.bat`) и разверните окно терминала пошире.
2. Включите запись экрана: **Win+Alt+R** (Xbox Game Bar) или OBS.
3. Запустите `demo.bat`: игра сама «напечатает» команды из [`demo/demo.txt`](demo/demo.txt) — пролог, сторожку, бой с крысой, вспышку против сажевика и карту. Демо длится около 30 секунд и всегда проигрывается одинаково (фиксированный seed).
4. Остановите запись (снова **Win+Alt+R**). Видео окажется в папке «Видео → Клипы».

## Структура репозитория

```
src/
  app/        main.cpp — параметры командной строки, запуск
  core/       Game, GameContext, машина состояний и 5 режимов игры, TurnSystem
  commands/   обработчики команд режима исследования
  parser/     нормализация ввода, разбор команд, поиск объектов по основам слов
  systems/    свет, перемещение, взаимодействия, бой, урон, сохранения, подсказки, счёт
  model/      определения (*Def), состояние мира (WorldState), словарь парсера
  data/       загрузка и проверка данных, формат сохранений
  ui/         консоль (Windows/POSIX), рендерер, описание комнат, ASCII-карта
  common/     идентификаторы, перечисления, MessageLog, IRandom, UTF-8
data/         config.json, world/*.json, lang/ru/*.json, записки и эпилоги
art/          ASCII-арт: титул, портреты врагов, баннеры зон, финалы
demo/         сценарий демо для видео
tests/        doctest: 37 тестов, включая автоматическое прохождение игры
third_party/  nlohmann/json 3.11.3, doctest 2.4.11 (MIT)
docs/         GDD, 1-pager, архитектура, питч
```

## Тесты

`build.bat test` запускает 37 тестов: UTF-8 и парсер, загрузку и проверку данных, формулы боя, механики света, загадки, сохранения, карту и **полное прохождение игры** по сценарию [`tests/walkthrough.txt`](tests/walkthrough.txt) — от главного меню до финала с эпилогом.
