# Последний фонарщик · The Last Lamplighter

Текстовая RPG в жанре dungeon crawler в духе **Zork** на **C++17**. Спуститесь в недра горы с фонарём, добудьте три Угля Сердца и снова разожгите погасшее Сердце Пламени.

Главный ресурс — масло в фонаре. Каждая тёмная комната сжигает масло, без света не видно ни предметов, ни выходов, а вспышка обжигает существ тьмы. Враги заранее объявляют свои намерения, и на них нужно отвечать.

28 комнат · 17 боёв (4 босса) · 9 загадок · около часа игры. Весь контент лежит во внешних файлах: `data/` и `art/`.

## Сборка и запуск

Windows: нужна Visual Studio 2022 с компонентом «Разработка классических приложений на C++».

```bat
build.bat          :: собрать в папку build\
play.bat           :: запустить игру
build.bat test     :: собрать и запустить тесты
```

Linux / macOS:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
./build/lamplighter
```

## Параметры запуска

| Параметр | Что делает |
|---|---|
| `--data DIR` | папка с `data/` и `art/` (по умолчанию ищется рядом с программой) |
| `--seed N` | фиксированная случайность: бои проходят одинаково |
| `--no-color` | без цветов |
| `--width N` | ширина текста (по умолчанию 78) |
| `--script FILE` | выполнить команды из файла, затем продолжить вручную |

## Как играть

Цель: найти три Угля Сердца (в шахтах, в кузне и в склепе), открыть Печать Сердца, победить Глотателя Света и `разжечь сердце`.

| Команда | Коротко |
|---|---|
| `идти север` | `с`, `ю`, `з`, `в`, `вв`, `вн` |
| `осмотреться` · `осмотреть <что>` | `о` |
| `взять <что>` · `взять всё` · `бросить <что>` | |
| `открыть <что>` · `читать <что>` | |
| `использовать <что> [на <чём>]` · `надеть <что>` | |
| `фонарь` · `зажечь <что>` | |
| `атаковать <кого>` · `отдохнуть` (у горящей жаровни) | |
| `инвентарь` · `статус` · `карта` · `журнал` | `и`, `ст`, `к` |
| `сохранить` · `загрузить` · `помощь` · `выход` | `?` |

В бою: `атака` (`а`), `блок` (`б`), `вспышка` (`в`), `использовать <предмет>`, `бежать`.

## Структура репозитория

```
src/          исходный код: app, core, commands, parser, systems, model, data, ui, common
data/         конфиг баланса, комнаты, предметы, враги, тексты, словарь команд
art/          ASCII-арт
tests/        тесты (doctest) и сценарий полного прохождения
third_party/  nlohmann/json, doctest
docs/         GDD, архитектура, питч, видео
```

## Тесты

`build.bat test` запускает 37 тестов: парсер, загрузку данных, формулы боя, свет, загадки, сохранения, карту и полное прохождение игры по сценарию [`tests/walkthrough.txt`](tests/walkthrough.txt).
