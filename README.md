# Последний фонарщик · The Last Lamplighter

> Спуститесь в недра горы с фонарём, в котором заканчивается масло, и разожгите погасшее Сердце Пламени, пока тьма не поглотила город — и вас.

Текстовая RPG в жанре dungeon crawler в духе **Zork**, написанная на **C++17**. Главный ресурс игры — масло в фонаре, и оно служит сразу трём целям:

- **время**: каждый шаг в темноте сжигает масло;
- **знание**: без света не видно ни предметов, ни выходов, остаются только звуки и запахи;
- **оружие**: вспышка обжигает существ тьмы.

Бои пошаговые, и враги заранее объявляют свои намерения. Мир состоит из 28 комнат в четырёх зонах, в нём 4 босса, а игру можно пройти примерно за час. Весь контент — комнаты, предметы, враги, тексты и ASCII-арт — хранится во внешних файлах.

## Планируемая структура репозитория

```
docs/          дизайн-документ, питч, архитектура (M2)
src/           исходный код на C++ (M3)
data/          мир, предметы, враги, баланс, тексты (JSON/TXT)
art/           ASCII-арт
third_party/   nlohmann/json (header-only)
tests/         модульные тесты (doctest)
```

## Сборка и запуск

Появится в M3. Планируется так:

```bash
cmake -S . -B build
cmake --build build --config Release
./build/lamplighter
```
